🚀 Está chegando mais um GDG Talks!

Prepare-se para uma noite de IA aplicada de verdade: três talks técnicos sobre como construir, arquitetar e colocar em produção sistemas de IA no Google Cloud Platform.

☁️ GCP Data Cloud — Plataforma unificada de IA e Analytics

Com Josias Leonardo Junior

O BigQuery e os componentes do Google Cloud não são ferramentas isoladas — são um ecossistema integrado para acelerar o desenvolvimento e uso de IA em escala. Nesta talk, você vai entender como a plataforma se posiciona como fundação segura e unificada para times que querem ir do dado bruto à IA em produção:

- O papel do BigQuery no ecossistema de dados do GCP

- Como os componentes da plataforma se integram

- Como acelerar o desenvolvimento de IA com segurança e escala

🔍 RAG em SQL: arquitetura de IA no GCP

Com Leonardo Henrique Oliveira Pena

RAG tem seis peças: extração, chunking, embedding, banco vetorial, orquestrador e serviço. A pergunta real é onde cada peça deve morar. Leonardo constrói um RAG inteiro dentro do BigQuery, em SQL puro, sem nova infraestrutura — e então mostra com honestidade onde essa arquitetura não serve:

- As seis peças de um RAG e onde cada uma pode rodar

- Por que construir tudo dentro do BigQuery, em SQL

- Os limites reais: latência, custo por linha e estado

- A fronteira entre uma query e um agente

🤖 Domando Multi-Agentes em Go com Phoenix

Com Guilherme Henrique da Silva

Criar um agente é a parte fácil. O desafio real é colocar sistemas multi-agentes em produção com segurança e observabilidade. Guilherme mostra como orquestrar agentes com Golang e monitorá-los com Phoenix:

- Orquestração de sistemas multi-agentes com Go

- Captura de dados gerados por agentes em produção

- Versionamento de prompts e gestão de experimentos

- Estruturação de datasets robustos sem comprometer performance

Vai ser uma noite de arquitetura real, decisões difíceis e IA que vai pra produção.
